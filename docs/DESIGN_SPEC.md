## 全局规则

- 内容区最大 1360px，不含流动左右边距。桌面导航 80px，移动导航 64px。
- 底色 `#070C15`，次级底色 `#0B1524`，架构图表面 `#101F32` / `#142740`。
- 主要文字 `#F3F6FC`，次级文字 `#A6B6CA`，强调蓝 `#4B91F2`，青色 `#45C5DC`。
- 蓝色实心按钮使用深色文字，避免浅蓝底白字对比不足；Hero 使用浅色主按钮。
- 主要正文 15–18px；栏目、日期、编号等辅助文字 13–14px。大标题按视口自适应，不把桌面布局整体缩放到手机。
- 英文优先本机 Latin 无衬线字体，中文使用既有 CJK 字体栈；没有引入外部字体请求。
- 以细线、材质、层级和排版建立区隔；首页无粒子、发光边框、循环球体或滚动显隐文案。
- 统一键盘焦点；导航抽屉、表单 label、校验、loading/error/retry 继续工作；遵守 `prefers-reduced-motion`。
- 平板：产品展廊改为两列，首页产品为三列；手机重排为单列，首页产品使用小图与文字并排。

素材为本轮生成并检查过的概念艺术，不是实际软件截图、真实办公场所、设备照片或产品已发布证明。

| 资产 | 用途 |

源图和提示词在 `design/phase2/`、`design/phase3/`，网页使用 `frontend/public/media/editorial-v2/` 中的 WebP。`frontend/scripts/prepare-editorial-assets.mjs` 仅缩放和编码，保留源 PNG。未知文章主题没有伪造封面；没有合适素材时使用纯文字排版。图片失败后保留真实内容与链接。

## 数据与语言

- 业务内容继续由既有 API 提供，固定 UI 文案由 Vue I18n 管理。产品阶段由 API 的 `productStage` 驱动，当前五产品均为 PLANNED。
- 不增加客户案例分类、白皮书下载、客户/团队/规模/性能指标。
- `/` 和没有语言前缀的地址默认进入 `/en`；显式 `/zh` 继续中文。语言切换保留当前页面。
- 初始 HTML 语言和前端 `x-default` 使用英文；中文与英文 canonical、hreflang 和预渲染均保留。
- ContactForm 的九字段、必填规则、提交载荷与 API 契约保持原定义。

## 检查方式

在真实 Chromium 中检查 1920×1080、1440×900、768×1024、390×844。全页截图前滚动并等待图片解码，避免把懒加载空白误当成设计结果。截图位于 `frontend/output/playwright/`；该目录为本机验证产物，不提交到版本库。
